# Five Seconds to Explain the Glass

A house cat gets five seconds to explain the glass on the floor — and delivers a flawless defence: the glass was plotting, the inspection was scheduled, and frankly the table is the one at fault.

## How to run

```sh
python3 main.py
```

That writes the 171-character excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if the variable is unset. Python 3 standard library only, no network, and the same bytes every time.
